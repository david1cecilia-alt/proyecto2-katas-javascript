# Katas de JavaScript

Colección de ejercicios de JavaScript del **1º de Ciberseguridad**, organizados por bloques de dificultad.

## Contenido

| Carpeta | Qué se practica |
|---|---|
| `ejercicios-basicos-avanzados/` | 42 ejercicios: variables, condicionales, bucles, funciones, arrays y objetos |
| `ejercicios-dom/` | 5 ejercicios de manipulación del DOM y eventos, cada uno con su `index.html` |
| `ejercicios-es6-asincronia/` | 9 ejercicios de ES6+ (destructuring, spread, métodos de array) y asincronía con `fetch` contra APIs públicas como PokeAPI |

## Cómo ejecutarlos

- Ejercicios sueltos: `node ejercicios-basicos-avanzados/Ejercicio1.js`
- Ejercicios de DOM o con `fetch` en el navegador: abre el `index.html` correspondiente.
